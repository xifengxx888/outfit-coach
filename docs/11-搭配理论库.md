## 0. 阅读说明与依据分级

### 0.1 这份文档解决什么

M1 原来的 `reason` 只是把命中的软规则按固定顺序拼成一句话。它回答的是「哪条规则加了分」，不是「为什么这样穿成立」。本轮新增解释层，要求每条解释都能追到：

1. 一套可复述的搭配原理（本文的 `P-*`）；
2. 一条真实执行的规则（`R-*`）；
3. 这套衣服上的具体证据（单品名、色差、尺寸、正式度、温度）。

解释层的职责边界：

- 只描述**已经发生**的规则命中，不重新打分、不改排序、不放宽/收紧任何阈值；
- 只对最终返回的组合生成，不进入 `solve()` 的热路径；
- 不调大模型，不做语义改写；
- 缺数据就写「未参与」，不补空话。

### 0.2 依据分级

搭配领域大量说法是行业惯例，不是实验科学。为了避免把「造型经验」包装成「科学结论」，每条原理强制标注等级：

| 等级 | 含义 | 典型例子 | 在界面上的说法 |
|---|---|---|---|
| **A 可测量科学** | 有公开公式或可复现的色度计算 | CIEDE2000、CIE Lab、Munsell 明度 | 「可测量」 |
| **B 实验与标准** | 有实验、行业标准或工程共识，但受场景影响 | Gestalt 视知觉、松量、着装规范、热舒适 | 「实验与标准」 |
| **C 造型经验** | 行业惯例与教学共识，缺少强实验证据 | 一宽一窄、鞋色呼应、材质对比 | 「造型经验」 |
| **D 数据不足** | 有说法，但当前字段无法计算或无法验证 | 60-30-10 精确比例、个人色彩季型、身材类型 | 不进入解释，只在第 8 节列出 |

**硬规则：C 级不得写成科学结论；D 级不得生成解释行。**

### 0.3 原理状态

| 状态 | 含义 | 在解释里的行为 |
|---|---|---|
| `active` | 当前衣柜能稳定产生正向解释行 | 正常参与选行 |

## 1. 视觉平衡与比例

### P-VIS-01 · 轮廓靠一宽一窄成立

- **主张**：上下装至少要有一侧收、一侧放；上下同宽会合并成一个方块，上下同紧会显得局促。
- **为什么**：人眼先读外轮廓，再读内部细节。肩线到下摆、腰头到裤脚是两条独立的体量信号；两侧体量相同，边界消失，身体被读成一个整体块。只有宽窄差足够大，才会出现明确的横向分割线。
- **怎么用（阈值/证据）**：
  - 上装代表件 = 有外套取外套，否则取内搭；
  - 版型序 `slim=1 / regular=2 / oversize=3`；
  - 上下差 ≥2 级 → 成立（如修身 + 宽松）；
  - 双方都是 `oversize` → 硬失败（R-PRP-01）；
  - 双方都是 `slim` → 硬失败（R-PRP-02）。
- **适用规则**：`R-PRP-01`、`R-PRP-02`、`R-PRP-03`
- **依据等级与来源**：**C 造型经验**。体量对比是造型教学共识，不是实验科学。来源：造型教学通行的 volume balance 原则；本项目以 `FIT_IDX` 把「宽/窄」离散化。
- **当前状态**：`active`。当前 19 件里存在 `slim/regular` 内搭与 `oversize` 运动裤的组合，能稳定产生「上窄下宽」正向行。

### P-VIS-02 · 外套下摆超过身高 55% 会压低重心

- **主张**：身高较矮时，外套下摆越长，视觉重心越低；超过身高的 55% 就不再是「长外套造型」，而是压身高。
- **为什么**：外套下摆是全身最明确的一条水平线，眼睛会把它当成躯干与腿的分界。下摆越低，腿的可见长度越短。对小个子，这条线的影响大于颜色和图案。
- **怎么用（阈值/证据）**：
  - 只对身高 <170cm 生效；
  - 阈值为 `0.55 × 身高`；165cm 对应 90.75cm；
  - 外套 `length_cm` ≥ 阈值 → 扣 1.0 分；
  - 无身高或无外套衣长 → 跳过，不猜。
- **适用规则**：`R-PRP-04`
- **依据等级与来源**：**C 造型经验**。55% 是本项目为可计算而设定的操作化阈值，不是人体测量学标准。来源：比例造型中「外套长度落在胯/大腿中段」的经验规则；本项目把它转成身高比例。
- **当前状态**：`dormant`。当前身高 165cm，最长外套 67cm，远低于 90.75cm 阈值，规则不会命中，也不会生成解释行。

## 2. 色彩关系

### P-COL-01 · 相邻色差低于 ΔE00 10 会糊成一片

- **主张**：相邻两层如果颜色不同、但色差太小，会看起来像「同一块布洗旧了」，而不是有意的层次。
- **为什么**：人眼对色差的分辨有下限。CIEDE2000 把色差归一化到「1 左右为刚可察觉」，10 左右是明确可辨的差异。低于这个量级、又属于不同色相家族时，视觉上既没有「同色系」的统一感，也没有「对比色」的分离感，只剩脏。
- **怎么用（阈值/证据）**：
  - 只看相邻上装之间、以及最外层上装与下装；
  - 不同色相家族且 `ΔE00 < 10` → 扣 2.0 分；
  - 同色相家族不走这条规则，走 P-COL-02。
- **适用规则**：`R-COL-02`
- **依据等级与来源**：**A 可测量科学**（色差公式）+ **C 造型经验**（10 的取舍）。来源：Sharma et al., *The CIEDE2000 Color-Difference Formula*, 2005。
- **当前状态**：`conditional`。只在相邻层「不同色相但色差过小」时产生负向 caveat；当前衣柜以中性色为主，命中不稳定。

### P-COL-02 · 同色系用明度差分层，比换色更稳

- **主张**：同一色相家族内拉开明度/色差，既保留统一感，又读得出层次。
- **为什么**：同色系不增加主色数量，视觉预算不被占用；明度差提供边界，让相邻层不粘在一起。相比换一个色相，同色系更难出错，也更容易重复。
- **怎么用（阈值/证据）**：
  - 相邻层同属一个色相家族；
  - `ΔE00 ≥ 10` → 加 2.0 分；
  - 证据里同时给出 HEX、ΔE00 与 L* 明度，避免只报一个抽象分数。
- **适用规则**：`R-COL-03`
- **依据等级与来源**：**A 可测量科学**（CIEDE2000 / CIE Lab）+ **C 造型经验**（同色系叠穿的优先级）。来源：Sharma et al., 2005；Itten 的色彩对比理论。
- **当前状态**：`active`。当前衣柜的灰/黑/藏青组合能稳定命中。

### P-COL-03 · 中性色是视觉锚点，能压住彩色

- **主张**：整套里至少有一件中性色（黑、白、灰、藏青、卡其等），整体更稳；彩色越多，越需要中性色兜底。
- **为什么**：中性色饱和度低、不争抢注意力，给其他颜色提供参照。没有中性色时，多个彩色会同时争夺「主色」位置，视觉上没有落点。
- **怎么用（阈值/证据）**：
  - 只要上装/下装/鞋中任意一件被判定为中性色 → 加 1.5 分；
  - 中性色判定使用 `color_math.is_neutral`：低饱和、黑、白、藏青、卡其；
  - 证据写明是哪一件、什么 HEX、为什么算中性。
- **适用规则**：`R-COL-06`
- **依据等级与来源**：**B 色彩理论与视知觉**。中性色作为 anchor 是色彩教学与设计基础中的稳定做法；具体阈值由本项目定义。来源：Itten 色彩对比理论；Albers *Interaction of Color* 中关于邻色与同时对比的讨论。
- **当前状态**：`active`。当前衣柜绝大多数单品是中性色，几乎每套都能产生这条正向行。

### P-COL-04 · 主色数量与饱和度是视觉预算

- **主张**：全身主色不超过 3 个；饱和度总量过高时，颜色会互相抢，失去主次。
- **为什么**：把颜色当成有限的注意力预算。每多一个高饱和主色，眼睛就多一个竞争焦点；超过 3 个后，观众记不住「这套的主色是什么」。
- **怎么用（阈值/证据）**：
  - 主色 = 非中性且饱和度 ≥15 的色相家族；
  - 主色家族数 >3 → 硬失败（R-COL-01）；
  - 全身饱和度合计 >200 → 扣 1.5 分（R-COL-05）；
  - **不声称 60-30-10 的精确面积比例**，当前字段算不出面积。
- **适用规则**：`R-COL-01`、`R-COL-05`
- **依据等级与来源**：**B 视知觉 + C 造型经验**。三色上限是通行配色建议；饱和度合计 200 是本项目的操作化阈值。来源：男装配色教学中「三色上限 / 2+1 结构」；Itten 关于色彩面积与强度的讨论。
- **当前状态**：`conditional`。当前没有 S≥60 的高饱和单品，饱和度合计也未接近 200；只会作为边界说明出现，不产生正向行。

### P-COL-05 · 高饱和冷 + 高饱和暖并置会互相抢

- **主张**：两件高饱和单品如果一冷一暖，会形成强烈的色彩冲突，除非这是刻意造型。
- **为什么**：高饱和本身已经占据注意力；冷暖对立又增加一层张力。两者同时出现时，眼睛找不到统一色温，整体会显得「吵」。
- **怎么用（阈值/证据）**：
  - 高饱和 = 饱和度 ≥60；
  - 同时存在高饱和冷色与高饱和暖色 → 硬失败（R-COL-04）；
  - 这是边界规则，只解释「为什么被拦下」，不包装成优点。
- **适用规则**：`R-COL-04`
- **依据等级与来源**：**B 色彩理论**。冷暖对比是 Itten 七种色彩对比之一；「高饱和 + 冷暖对立」的风险有教学共识，但阈值 60 是本项目设定。
- **当前状态**：`boundary`。当前衣柜没有 S≥60 的单品，规则不会命中。

### P-COL-06 · 鞋与上身同色系形成上下呼应

- **主张**：鞋的颜色如果与内搭/中层/外套/配饰属于同一色相家族，整套会形成上下呼应，视觉更完整。
- **为什么**：鞋在全身最底部，是视线的收尾。它与上身同色系时，颜色从上半身「落」到脚上，形成闭环；完全孤立的鞋色会把身体切成两段。
- **怎么用（阈值/证据）**：
  - 鞋与任一上装或配饰同色相家族；
  - 且 `ΔE00 < 25` → 加 1.5 分；
  - 证据写明鞋与哪一件呼应、色差多少。
- **适用规则**：`R-SHO-02`
- **依据等级与来源**：**B 视知觉 + C 造型经验**。相似性归类有 Gestalt 依据；「鞋色呼应」是造型惯例。来源：Gestalt 相似性原理；鞋履造型教学中「shoe color echo」的通行做法。
- **当前状态**：`active`。当前鞋以白/黑/灰为主，与中性色上装能稳定命中。

## 3. 层次结构

### P-LAY-01 · 叠穿厚度由内到外不减

- **主张**：内层薄、外层厚是默认结构；内厚外薄会显得臃肿，也不符合穿脱与热舒适逻辑。
- **为什么**：厚度顺序同时是版型顺序与热舒适顺序。内层厚会在肩、腋下堆积，外层再薄也压不住；反过来，内薄外厚能提供可调节的空气层。
- **怎么用（阈值/证据）**：
  - 上装按内→外排序，厚度序 `thin=1 / medium=2 / thick=3`；
  - 正常要求非递减；
  - 只有放宽容差 ≥1.5 时，允许出现一次 -1 级倒挂；
  - 严格档倒挂 → 硬失败（R-LYR-01）。
- **适用规则**：`R-LYR-01`
- **依据等级与来源**：**B 版型/热舒适**。叠穿顺序有服装工程与热舒适共识；具体容差由本项目定义。来源：服装松量与叠穿结构常识；项目 `R-OCC-01/03` 的厚度口径。
- **当前状态**：`baseline`。它主要作为结构底线，在正向行不足时补一条「厚度没有倒挂」。

### P-LAY-02 · 三层长度差 ≥5cm，层次才读得出来

- **主张**：三层上装的下摆要逐层错开，相邻长度差至少 5cm；下摆齐平会把三层合并成一条线。
- **为什么**：下摆是层次最直接的边界。差太小，眼睛读不出「里面还有一层」；差足够大，才会出现明确的阶梯。5cm 是项目内可操作的下限，不是绝对美学标准。
- **怎么用（阈值/证据）**：
  - 至少 3 层上装，且每层都有 `length_cm`；
  - 相邻长度差均 ≥5cm → 加 1.5 分；
  - 任一层缺长度 → 跳过，不猜。
- **适用规则**：`R-LYR-02`
- **依据等级与来源**：**B 视知觉 + C 造型经验**。Gestalt 接近/相似原理支持「边界分离才读得出层」；5cm 来自造型教学中的下摆错层建议（约 5cm / 2 英寸）。来源：ELLE UK 关于 rule of thirds 与下摆错层的造型指南；Gestalt 组织原则。
- **当前状态**：`active`。当前有可组成三层的上装，且衣长已量，能产生正向行。

### P-LAY-03 · 重复领型会合并成一个视觉块

- **主张**：两层上装如果都是高领或都是连帽，领口会合并成一个视觉块，层次消失。
- **为什么**：Gestalt 相似性会把形状、位置接近的元素归为一组。两个同形领口叠在一起，观者读到的不是「两层」，而是「一个更厚的领子」。
- **怎么用（阈值/证据）**：
  - 任意两件上装领型相同，且属于 `高领` / `连帽` → 扣 1.5 分；
  - 其他领型重复不扣，避免把圆领 T 恤 + 圆领卫衣误判。
- **适用规则**：`R-LYR-03`
- **依据等级与来源**：**B 视知觉**。Gestalt 相似性；领型重复的具体惩罚由本项目设定。
- **当前状态**：`dormant`。当前衣柜没有可同时上身的双高领/双连帽组合，规则不会命中。

## 4. 材质与图案

### P-TEX-01 · 外层挺括、内层柔软，材质对比撑轮廓

- **主张**：外层用挺括材质（牛仔、皮革、尼龙、羊毛、帆布、防水涂层），内层用柔软材质（棉、针织、亚麻、化纤、缎面、麂皮），轮廓更清楚。
- **为什么**：挺括外层提供形状，柔软内层负责贴身与舒适；两者形成「骨架 + 填充」的关系。内外都软会塌，内外都硬会僵。
- **怎么用（阈值/证据）**：
  - 相邻两层，外层属于挺括集合、内层属于柔软集合 → 加 1.5 分；
  - 材质缺失 → 跳过；`不确定` 不当作任一集合。
- **适用规则**：`R-MAT-01`
- **依据等级与来源**：**C 造型经验**。材质对比是造型教学共识，缺少强实验证据；材质分类由本项目定义。来源：服装造型中「structure vs drape」的通行区分。
- **当前状态**：`dormant`。当前两件外层夹克都是棉，内层也以棉为主，没有「挺括外层 + 柔软内层」的组合，规则不会命中。

### P-PAT-01 · 全身只保留一个图案焦点

- **主张**：全身大图案不超过 1 件；如果只有一件，让它落在视觉主体位（外套或下装），其余保持纯色。
- **为什么**：图案自带注意力。两件大图案会互相争夺焦点；一件大图案放在外套/下装，能把视线引到想强调的区域，其余纯色提供留白。
- **怎么用（阈值/证据）**：
  - `pattern=bold` 件数 >1 → 硬失败（R-PAT-01）；
  - 恰好 1 件，位于外套或下装，其余 `solid` → 加 1.0 分（R-PAT-02）。
- **适用规则**：`R-PAT-01`、`R-PAT-02`
- **依据等级与来源**：**B 视知觉 + C 造型经验**。焦点唯一性有视知觉依据；「主体位」的槽位定义由本项目设定。来源：Gestalt 图底关系；造型教学中「一个 statement piece」的惯例。
- **当前状态**：`dormant`。当前 19 件全部 `pattern=solid`，没有图案焦点。

## 5. 合身与结构

### P-FIT-01 · 上装合身看肩线、胸围松量、袖长

- **主张**：上装是否合身，先看肩线落点，再看胸围松量，最后看袖长；三项里最差的一项决定整体判断。
- **为什么**：肩线是上装的骨架，落点错了整件衣服的受力线就错了；胸围松量决定能否活动与是否有垂坠；袖长影响手臂比例。三项分开判断，才能指出「哪里不合」而不是笼统说「不合身」。
- **怎么用（阈值/证据）**：
  - 肩宽：偏差 ≤2.5cm 合适；≤7cm 中性；过窄 -1.0；落肩过多 -0.5；
  - 胸围松量：按槽位与版型查矩阵；过紧 -1.0，过松 -0.5，容差 1.0cm；
  - 袖长：≥40cm 视为长袖；超出允许值 8cm 扣 -0.5；
  - 三项都合适时给 `0.2 × 最小维度权重` 的加分；
  - 整体下限 -2.5；
  - 证据必须写明是哪一件、哪个维度、偏差多少。
- **适用规则**：`R-SIZ-01`
- **依据等级与来源**：**B 版型结构**。松量与肩线是版型工程的基本参数；具体阈值由本项目标定。来源：Aldrich *Metric Pattern Cutting*、Armstrong *Patternmaking for Fashion Design* 中关于 ease 与 shoulder line 的章节。
- **当前状态**：`active`。身体肩宽/胸围与衣件平铺尺寸已接入，能稳定产生正向或负向行。

### P-FIT-02 · 下装臀围松量兼顾坐姿与垂坠

- **主张**：裤子的臀围松量要够坐、又不能大到失去垂坠；松量落在合适区间才算合身。
- **为什么**：臀围是裤子活动量的核心。过紧坐下会绷，过松会在胯部堆布，破坏裤线。它和腰围不同，受低腰与弹力腰头影响小，更适合作为可计算指标。
- **怎么用（阈值/证据）**：
  - 裤臀围（平铺 ×2）− 身体臀围 = 松量；
  - 松量 <0 → 过紧，-1.0；
  - 0–2cm → 偏贴，+0.1；
  - 2–10cm → 合适，+0.2；
  - >10cm → 偏肥，-0.3；
  - 下限 -1.0；
  - 缺裤臀围或身体臀围 → 跳过。
- **适用规则**：`R-SIZ-02`
- **依据等级与来源**：**B 版型结构**。裤装臀围松量是版型工程参数；区间由本项目标定。来源：Aldrich / Armstrong 的裤装松量章节。
- **当前状态**：`active`。身体臀围与裤臀围已接入，能稳定产生正向或负向行。

## 6. 社会语境：正式度、场合、鞋

### P-SOC-01 · 正式度要在全身连续

- **主张**：正式度是一条连续谱，不是单件标签。相邻层差不超过 1 档，全身极差不超过 2 档；鞋也要跟全身同调。
- **为什么**：人读到的是整套的「场合信号」，不是每件衣服的标签。上半身正装、下半身运动，或者鞋突然跳出两个档位，会让整套的语境断裂。连续性比单件精确更重要。
- **怎么用（阈值/证据）**：
  - 正式度 1–5；
  - 相邻上装差 >1 → 硬失败（R-FRM-01）；
  - 全身（上装 + 下装）极差 >2 → 硬失败（R-FRM-02）；
  - 鞋与全身均值差 >1 → 硬失败（R-SHO-01）；
  - 放宽档只允许 ±0.5 / ±1.0 / ±2.0 的容差，且必须在界面标注。
- **适用规则**：`R-FRM-01`、`R-FRM-02`、`R-SHO-01`
- **依据等级与来源**：**B 着装规范**。正式度分档有通行定义，但具体数值是本项目的操作化。来源：Business formal / Business casual / Smart casual / Casual 的通行定义（Wikipedia 作为可核对入口）。
- **当前状态**：`baseline`。它主要作为结构底线，在正向行不足时补一条「正式度没有断层」。

### P-SOC-02 · 场合决定正式度目标区间

- **主张**：日常与旅游的目标正式度是 2.0–3.0；见人是 3.5–4.5。整套均值落在区间内，场合才匹配。
- **为什么**：同一套衣服在不同场合的「对不对」不同。场合不是风格标签，而是一个可计算的正式度目标区间；先定目标，再谈单品。
- **怎么用（阈值/证据）**：
  - 主集合 = 上装 + 下装 + 鞋；
  - 均值落在 `OCCASION_FORMALITY[occasion]` 内 → 加 2.0 分；
  - 不在区间内 → 规则 SKIP，不扣分，但解释层会生成一条 context caveat，写明差多少；
  - 证据写明场合、均值、目标区间。
- **适用规则**：`R-OCC-02`
- **依据等级与来源**：**B 着装规范**。场合与正式度的对应有通行共识；区间由本项目设定。
- **当前状态**：`active`。日常场景能稳定命中「日常正式度刚好」。

### P-SOC-03 · 穿多少由体感温度决定；雨天材质优先

- **主张**：层数与厚度要跟体感温度匹配；降水时鞋的材质优先选皮革、橡胶、防水涂层，避开麂皮、帆布、缎面。
- **为什么**：体感温度包含风速与湿度，比气温更接近身体实际感受。穿多穿少是热舒适问题，不是审美问题；雨天则是功能问题，湿鞋会直接破坏整套体验。
- **怎么用（阈值/证据）**：
  - 温度带：≥26°C 只内层；18–26°C 单层或薄外套；10–18°C 需中层或外套；<10°C 三层；
  - 任一温度带通过 → R-OCC-01 通过；全不通过 → 硬失败；
  - 暖度目标 `clamp(1 + (30 − 体感温度) / 7, 1, 5.5)`；均值差 ≤0.5 → 加 1.5 分（R-OCC-03）；
  - 降水时：麂皮/帆布/缎面 -1.5；皮革/橡胶/防水涂层 +1.0（R-SHO-03）；
  - 缺体感温度或厚度 → 跳过。
- **适用规则**：`R-OCC-01`、`R-OCC-03`、`R-SHO-03`
- **依据等级与来源**：**B 热舒适/功能**。体感温度与分层穿衣有共识；具体公式与温度带由本项目定义。来源：Open-Meteo Apparent Temperature 文档；项目既有温度带实测。
- **当前状态**：`active`。体感温度与厚度已接入，日常场景能稳定产生正向行。

## 7. 风格形成：为什么重复看解释会形成审美

风格不是一个标签，而是四个可计算决策的稳定组合：

1. **廓形**：上宽下窄 / 上窄下宽 / 上下均衡；
2. **配色**：中性色主导 / 一个主色 + 中性色 / 多主色 / 低饱和；
3. **层次**：单层 / 两层 / 三层，以及下摆是否错开；
4. **精致度**：正式度带，从运动休闲到正式。

`explain()` 从这四轴生成一个**推断式**风格标签，例如「日常 · 上窄下宽 · 中性色主导（偏极简）」。它必须：

- 带「推断」徽标；
- 给出具体依据（正式度均值、版型、中性色比例、饱和度合计）；
- 明确说明「没有风格标签、配饰、鞋型数据，不参与评分」；
- 不声称是个人色彩季型或身材类型结论。

重复看解释的价值不在记住某一条规则，而在形成一套可迁移的判断顺序：**先看轮廓，再看颜色预算，再看层次边界，最后看场合与温度**。每次解释都按这个顺序展示，看多了就会用同一顺序看自己的衣服。

> 依据：Anuschka Rees,《The Curated Closet》把风格拆成 silhouette / color / fabric / refinement 四个决策，而不是一个风格名词。这与本项目的四轴推断一致。

## 8. 数据不足，暂不判定

以下主题写进知识库，但**不进入每套解释**。每条都写明需要补什么，作为 M2 的输入。

| 主题 | 为什么暂不判定 | 需要补什么 |
|---|---|---|
| 60-30-10 精确面积比例 | 当前没有单品面积/遮挡面积，只能判「主色 ≤3」 | 单品在身上的可见面积估算 |
| 个人色彩季型 / 冷暖肤色 | 没有肤色、发色、试色记录 | 肤色/发色字段 + 试色照片 |
| 身材类型（A/H/X/Y/O） | 没有肩宽/臀宽比例、腰围、内长 | 腰围、内长、肩宽与臀宽比例 |
| 腿长比例与腰线位置 | 没有内缝长、腰高 | 内长、裤裆深、腰线高 |
| 图案尺度、方向、位置 | 只有 `pattern=bold` 计数 | 图案尺寸、方向、分布 |
| 面料纹理、垂坠、光泽 | `material` 只有粗分类，VLM 材质准确率约 67% | 更细的材质与克重字段 |
| 鞋型、鞋跟、鞋头 | 只有材质与颜色 | 鞋型/鞋头/跟高字段 |
| 配饰、包、腰带 | 当前没有配饰品类，规则不消费 | 配饰类型与颜色字段 |
| 极简/街头/法式等风格原型 | 没有 style tags、品牌、版型数据 | 风格标签或品牌/版型数据 |
| 地区着装差异 | 当前只有单用户、单地点 | 多地点与场合画像 |

这些主题在 `/theory` 页底部单独列出，并明确写「当前不计算」。
